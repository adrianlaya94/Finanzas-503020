# Finanzas 50/30/20

App web de presupuesto personal (regla 50/30/20) pensada para iPhone.

## Funciones
- Ingresos y gastos en Bs, $ o €, con **tasa de compra opcional** (a cuánto compraste las divisas)
- Tasas del día: BCV dólar, BCV euro y **USDT promedio Binance P2P**, con brecha vs BCV
- Tocar una barra 50/30/20 abre sus movimientos: editar, eliminar, agregar o **ajustar el total usado**
- Eliminar con opción de deshacer
- Gráficos de distribución y de 6 meses
- Alertas al llegar al 90% y al superar el 100% de una categoría
- Metas de ahorro (cada una en su moneda) con abonos
- Gastos recurrentes editables (se registran solos cada mes)
- Exportar a CSV (con moneda, tasa y equivalente), respaldo y restauración en JSON
- Datos guardados en el navegador (localStorage)

## Uso
Abre `index.html` o publícala con GitHub Pages.
